# Конструктор отчетов по работам на сайтах

Небольшое веб-приложение для быстрого создания отчетов по выполненным изменениям на сайтах.

## Возможности

- заполнение шапки отчета: клиент, проект/сайт, период;
- добавление пунктов работ с датой, заголовком и подробным описанием;
- прикрепление нескольких изображений или скриншотов к каждому пункту;
- автоматическая сортировка и группировка пунктов по датам;
- предпросмотр документа в аккуратном формате;
- экспорт в PDF через стандартную печать браузера.

## Запуск

```bash
npm install
npm run start
```

Откройте `http://localhost:5173` в браузере.

## Как сохранить PDF

1. Заполните данные отчета и добавьте пункты работ.
2. Нажмите кнопку **Сохранить в PDF**.
3. В системном окне печати выберите принтер **Save to PDF / Сохранить как PDF**.
4. Сохраните файл.
